### 3. Схема установки

* \(H\) — высота цилиндра;
* \(D\) — внешний диаметр цилиндра;
* \(d\) — внутренний диаметр (диаметр отверстия).

```text

      |<--- d --->|
      +-----------+
     /    (   )    \
    +---------------+  ---

    |     |   |     |   ^
    |     |   |     |   |
    |     |   |     |   | H
    |     |   |     |   |
    |     |   |     |   v
    +---------------+  ---

    |<------ D ---->|
```

---

### 4. Рабочая формула

$$\rho = \frac{m}{\frac{\pi}{4}(D^2 - d^2)H}$$

где:
* $\rho$ — плотность тела;
* $m$ — масса тела;
* $D$ — внешний диаметр;
* $d$ — внутренний диаметр;
* $H$ — высота.

---

### 5. Формулы для расчёта погрешностей

Среднее значение измерений:
$$\bar{x} = \frac{1}{N}\sum_{i=1}^{N} x_i$$

Случайные погрешности прямых измерений ($N = 5$, коэффициент Стьюдента $t_{0{,}95;\, 5} = 2{,}78$):
$$\Delta D_a = t_{\alpha, N} \sqrt{\frac{\sum_{i=1}^{N}(D_i - \bar{D})^2}{N(N-1)}}$$

$$\Delta d_a = t_{\alpha, N} \sqrt{\frac{\sum_{i=1}^{N}(d_i - \bar{d})^2}{N(N-1)}}$$

$$\Delta H_a = t_{\alpha, N} \sqrt{\frac{\sum_{i=1}^{N}(H_i - \bar{H})^2}{N(N-1)}}$$

Полные абсолютные погрешности прямых измерений:
$$\Delta x = \sqrt{\Delta x_a^2 + \Delta x_{\text{приб}}^2}$$

Относительная погрешность косвенного измерения плотности:
$$\varepsilon = \sqrt{\left(\frac{\Delta m}{m}\right)^2 + \left(\frac{\Delta H}{\bar{H}}\right)^2 + \left(\frac{2\bar{D}\Delta D}{\bar{D}^2 - \bar{d}^2}\right)^2 + \left(\frac{2\bar{d}\Delta d}{\bar{D}^2 - \bar{d}^2}\right)^2}$$

Абсолютная погрешность плотности:
$$\Delta \rho = \varepsilon \cdot \bar{\rho}$$

### 9. Расчёт погрешностей измерений

### Вывод и расчёт погрешности косвенного измерения через частные производные

Плотность тела $\rho$ является функцией нескольких независимых измеряемых величин: $\rho = f(m, D, d, H)$.

$$\rho(m, D, d, H) = \frac{4m}{\pi(D^2 - d^2)H}$$

#### 1. Нахождение частных производных

Найдём частные производные функции $\rho$ по каждому параметру в средних точках ($\bar{m} = 130{,}9\text{ г}$, $\bar{D} = 58{,}87\text{ мм}$, $\bar{d} = 16{,}10\text{ мм}$, $\bar{H} = 65{,}32\text{ мм}$):

1. **Частная производная по массе $m$:**
   $$\frac{\partial \rho}{\partial m} = \frac{4}{\pi(\bar{D}^2 - \bar{d}^2)\bar{H}} = \frac{\bar{\rho}}{\bar{m}}$$
   $$\frac{\partial \rho}{\partial m} = \frac{795{,}8}{130{,}9} \approx 6{,}08\text{ кг/(м}^3 \cdot \text{г)}$$

2. **Частная производная по внешнему диаметру $D$:**
   $$\frac{\partial \rho}{\partial D} = -\frac{8\bar{m}\bar{D}}{\pi(\bar{D}^2 - \bar{d}^2)^2\bar{H}} = -\frac{2\bar{D}\bar{\rho}}{\bar{D}^2 - \bar{d}^2}$$
   $$\left|\frac{\partial \rho}{\partial D}\right| = \frac{2 \cdot 58{,}87 \cdot 795{,}8}{58{,}87^2 - 16{,}10^2} = \frac{93\,697{,}5}{3206{,}47} \approx 29{,}22\text{ кг/(м}^3 \cdot \text{мм)}$$

3. **Частная производная по внутреннему диаметру $d$:**
   $$\frac{\partial \rho}{\partial d} = \frac{8\bar{m}\bar{d}}{\pi(\bar{D}^2 - \bar{d}^2)^2\bar{H}} = \frac{2\bar{d}\bar{\rho}}{\bar{D}^2 - \bar{d}^2}$$
   $$\left|\frac{\partial \rho}{\partial d}\right| = \frac{2 \cdot 16{,}10 \cdot 795{,}8}{58{,}87^2 - 16{,}10^2} = \frac{25\,624{,}8}{3206{,}47} \approx 7{,}99\text{ кг/(м}^3 \cdot \text{мм)}$$

4. **Частная производная по высоте $H$:**
   $$\frac{\partial \rho}{\partial H} = -\frac{4\bar{m}}{\pi(\bar{D}^2 - \bar{d}^2)\bar{H}^2} = -\frac{\bar{\rho}}{\bar{H}}$$
   $$\left|\frac{\partial \rho}{\partial H}\right| = \frac{795{,}8}{65{,}32} \approx 12{,}18\text{ кг/(м}^3 \cdot \text{мм)}$$

---

#### 2. Расчёт среднеквадратичной абсолютной погрешности ($\Delta \rho$)

При независимых случайных ошибках итоговая абсолютная погрешность вычисляется как корень из суммы квадратов произведений частных производных на абсолютные погрешности соответствующих величин:

$$\Delta \rho = \sqrt{\left(\frac{\partial \rho}{\partial m}\Delta m\right)^2 + \left(\frac{\partial \rho}{\partial D}\Delta D\right)^2 + \left(\frac{\partial \rho}{\partial d}\Delta d\right)^2 + \left(\frac{\partial \rho}{\partial H}\Delta H\right)^2}$$

Подставим числовые значения ($\Delta m = 0{,}12\text{ г}$, $\Delta D = 0{,}471\text{ мм}$, $\Delta d = 0{,}1266\text{ мм}$, $\Delta H = 0{,}1235\text{ мм}$):

$$\Delta \rho = \sqrt{(6{,}08 \cdot 0{,}12)^2 + (29{,}22 \cdot 0{,}471)^2 + (7{,}99 \cdot 0{,}1266)^2 + (12{,}18 \cdot 0{,}1235)^2}$$

$$\Delta \rho = \sqrt{0{,}73^2 + 13{,}76^2 + 1{,}01^2 + 1{,}50^2} = \sqrt{0{,}53 + 189{,}34 + 1{,}02 + 2{,}25} = \sqrt{193{,}14} \approx 13{,}9\text{ кг/м}^3 \approx 14\text{ кг/м}^3$$

---

#### 3. Расчёт предельной (максимальной) абсолютной погрешности ($\Delta \rho_{\text{пред}}$)

Если требуется оценить максимально возможную границу ошибки (метод сложения модулей дифференциалов), используется сумма:

$$\Delta \rho_{\text{пред}} = \left|\frac{\partial \rho}{\partial m}\right|\Delta m + \left|\frac{\partial \rho}{\partial D}\right|\Delta D + \left|\frac{\partial \rho}{\partial d}\right|\Delta d + \left|\frac{\partial \rho}{\partial H}\right|\Delta H$$

$$\Delta \rho_{\text{пред}} = 0{,}73 + 13{,}76 + 1{,}01 + 1{,}50 = 17{,}0\text{ кг/м}^3 \quad (0{,}017\text{ г/см}^3)$$



---

### 14. Вывод

Материалом тела, скорее всего, является **ясень** или **дуб**:
* плотность ясеня по таблице: $0{,}750\text{–}0{,}800\text{ г/см}^3$;
* плотность дуба по таблице: $0{,}801\text{–}0{,}810\text{ г/см}^3$.

Измеренная плотность тела составляет $\rho = (0{,}796 \pm 0{,}014)\text{ г/см}^3$ (доверительный интервал от $0{,}782$ до $0{,}810\text{ г/см}^3$), что попадает в табличный диапазон плотности ясеня и на нижнюю границу плотности дуба.
